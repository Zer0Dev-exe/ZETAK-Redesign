## Stack

Astro 5 · plain CSS · vanilla TypeScript. No frameworks, no trackers.

## Run it

```bash
npm install
npm run dev     # http://localhost:4321
npm run build
```

The site expects images in `public/img/` (`logo-white.png`, `logo-black.png`,
`bg5.jpg`…`bg8.jpg`, `fetxagabe.jpg`) plus favicons in `public/`. They are not
in the repo; add your own or ones you have permission to use.
Content (dates, links) lives in `src/data/content.ts` and is placeholder data.
